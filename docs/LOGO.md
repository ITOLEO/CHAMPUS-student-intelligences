# CHAMPUS mark

The mark is an open letter C built from three pieces. It follows the product sequence “From learning to opportunity.”

| Part | Meaning | Product connection |
| --- | --- | --- |
| Navy base | What the student can demonstrate | An artifact and a rubric result support an observable skill. |
| Indigo side | What the student can develop | A learning action addresses a specific indicator. |
| Indigo upper piece | Where the student can apply that skill | A published opportunity gives the student an external destination. |

The gap on the right opens the C to the next step. The three pieces remain distinct at one color. Their order and shape carry the meaning.

## Use in the site

Use `public/champus.svg` for the browser icon and the header and footer lockups. Keep the live text “CHAMPUS” next to the icon in navigation. The home link supplies the accessible name “CHAMPUS home”. Give the adjacent image an empty alt attribute to avoid reading the brand twice. The SVG includes a title for standalone use.

Retain the square viewBox, inner margins and rounded light tile. Scale width and height together. Use 16 pixels or larger for the browser icon. Use 26 pixels or larger for a navigation lockup. At larger sizes retain the same three shapes and the same gap.

## Colors

| Element | sRGB |
| --- | --- |
| Evidence base | `#1D2B46` |
| Learning and opportunity pieces | `#4D63E8` |
| Tile | `#F4F5FF` |

These colors identify the product. Eligibility and review status require their own text labels. The mark does not indicate assessment status or campus endorsement.
